# SVNAssist 0.8.0

Versione in preparazione, in collaudo.

## Novità

- **Show Log delle righe selezionate.** Nell'editor, tasto destro su una riga o su un blocco di righe > **SVN: Show Log for Selected Lines**: si apre il solito **Log** con solo le revisioni che hanno toccato quelle righe, dalla più recente a quella che le ha create.
  - I merge compaiono con sotto le revisioni originali e il ramo da cui arrivano, anche dopo più merge a catena.
  - Le righe modificate in locale si riportano alla versione committata; le righe aggiunte e non ancora committate non hanno storia e il Log lo dice.

## Requisiti e installazione

Installazione: sostituisce la 0.7.2. Chiudere Visual Studio e avviare il file VSIX della release.

<details><summary>Dettagli tecnici</summary>

- `LineHistory` (puro): `svn log --diff` del file diviso per revisione e righe seguite all'indietro blocco per blocco (`LineRevert.ParseHunks`); prima il `svn diff` locale riporta le righe sulla BASE.
- `LogStore.StartLineHistoryAsync`: Log sul file con `SvnLogFilter.Revisions` (un `-r` per revisione) e `-g` chiesto alla radice della working copy (sul singolo file svn non sempre espande i merge); dentro i merge restano solo le revisioni che toccano lo stesso percorso relativo (`KeepTouching`).
- Host: comando `CmdLineLog` nel menu dell'editor (`GroupCode`), `RunPathCommandAsync("linelog", [file, "da-a"])`.

</details>
