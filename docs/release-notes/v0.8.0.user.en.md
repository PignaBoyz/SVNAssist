# SVNAssist 0.8.0

Version in preparation, being tested.

## New

- **Show Log for the selected lines.** In the editor, right-click a line or a block of lines > **SVN: Show Log for Selected Lines**: the usual **Log** opens with only the revisions that touched those lines, from the most recent to the one that created them.
  - Merges show the original revisions and the branch they come from underneath, even after several chained merges.
  - Lines modified locally are mapped to the committed version; lines added and not committed yet have no history and the Log says so.

## Requirements and installation

Installation: replaces 0.7.2. Close Visual Studio and run the VSIX file from the release.

<details><summary>Technical details</summary>

- `LineHistory` (pure): the file's `svn log --diff` split by revision and the lines followed backwards hunk by hunk (`LineRevert.ParseHunks`); the local `svn diff` first maps the lines onto BASE.
- `LogStore.StartLineHistoryAsync`: Log on the file with `SvnLogFilter.Revisions` (one `-r` per revision) and `-g` asked at the working copy root (on a single file svn does not always expand merges); inside merges only the revisions touching the same relative path are kept (`KeepTouching`).
- Host: `CmdLineLog` command in the editor menu (`GroupCode`), `RunPathCommandAsync("linelog", [file, "from-to"])`.

</details>
