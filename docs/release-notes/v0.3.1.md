# SVNAssist 0.3.1 — correzioni dal collaudo

Patch sulla 0.3.0. Si installa come la 0.3.0 (`SVNAssist.vsix`, Visual Studio chiuso).

## Correzioni
- **Ctrl+Z dopo "Annulla le righe"**: se il file è aperto (editor o diff) la modifica viene applicata al buffer con un'unica operazione annullabile e poi salvata; se non è aperto si scrive su disco come prima.
- **Controllo nuove revisioni**: non parte con Visual Studio in secondo piano; tornando in primo piano controlla subito se l'ultimo controllo è più vecchio dell'intervallo.
- **Log dell'host** in `%LOCALAPPDATA%\SVNAssist\logs\host-AAAAMMGG.log` (come il backend), scritto in condivisione così più istanze di Visual Studio non si bloccano a vicenda. Il vecchio `host-log.txt` non viene più usato.
- **Diagnostica del pulsante Annulla nel diff**: il log dice ruoli della vista, se il viewer è stato trovato, quante differenze e quanti pulsanti sono stati creati.

## Limiti noti
- Il pulsante Annulla accanto ai blocchi del diff non è ancora verificato in Visual Studio: se manca, il log host indica il motivo.
- Il file aperto solo come pannello di un diff, senza una finestra editor propria, viene ancora riscritto su disco (Ctrl+Z non lo annulla).
- Con modifiche non salvate le righe delle scorciatoie "modifica successiva/precedente" possono slittare.
