# SVNAssist 0.4.0 — Solution Explorer, Show Log completo, switch e merge guidati

Si installa come le precedenti (`SVNAssist.vsix`, Visual Studio chiuso). Include le correzioni della 0.3.2 (non rilasciata a parte).

## Finestra SVN Changes
- **Canc anche sulle cartelle**: versionate → `svn delete` (restano da committare); non versionate → cestino. Conferma con l'elenco.
- **Commit All con file nuovi**: se ci sono file non versionati chiede "Aggiungerli al commit?" (Sì, aggiungi e committa / No, solo i versionati / Annulla). Funziona anche con soli file nuovi. Commit Staged invariato.
- **AI**: nel menu del messaggio, oltre a Genera, **Più corto** e **Più dettagliato**.

## Show Log
- **Stop on copy/rename** (spento di default: storia completa oltre copie e rinomine).
- **Include merged revisions** (`svn log -g`): revisioni entrate per merge annidate sotto il merge, merge inverso segnalato.
- Clic su un file di una revisione → **diff** di quella revisione, anche per le revisioni unite.
- Le opzioni si cambiano mentre guardi il log, che si ricarica subito.

## Solution Explorer
- **Icone di stato SVN** (normale, modificato, aggiunto, non versionato, conflitto, eliminato), attive di default, disattivabili da Options. SVNAssist si registra come provider di source control solo per le soluzioni dentro una working copy SVN.
- Tasto destro → **Show Log** (file, progetto `.csproj`/`.vcxproj`, cartella), **SVN Add** (solo non versionati, anche selezione multipla), **Check for Modifications** (solo modificati: diff di VS rispetto a BASE).

## Switch, Merge, Update, Cleanup
- **Avviso prima dello switch** su working copy sporca (conteggi per tipo): Continua comunque / Apri Cleanup / Annulla.
- **Cleanup con opzioni** come TortoiseSVN da ogni punto di avvio: Break locks, Fix timestamps, Vacuum pristines, Include externals; le distruttive (Delete unversioned, Delete ignored, Revert) in rosso con conferma. Con svn < 1.9 le extra sono disabilitate.
- **Finestra di avanzamento** modale: fase corrente, righe di svn in streaming, conflitti evidenziati, riepilogo finale con **Apri i conflitti**.
- **Annulla** per Switch, Update e Merge (termina svn):
  - switch/update annullato → cleanup normale, avviso che la working copy può essere a metà, **Cleanup…**, **Completa switch** / **Torna a prima dello switch** (o **Riprova update**);
  - merge annullato → **Revert delle modifiche del merge** (con conferma) o **Lascia così**.

## Switch interrotto (dalla 0.3.2)
- Errore E155009 e simili: cleanup automatico + nuovo tentativo; se resta a metà, stato "switch incompleto" anche dopo il riavvio di VS.
- **Completa switch** e, novità, **Torna a prima dello switch** (URL e revisione di partenza salvati prima dello switch; le modifiche locali restano).
- Errori leggibili per intero e copiabili.

## Prerequisiti
- Dopo aver installato svn, .NET o le CLI AI **non serve riavviare il PC**: SVNAssist rilegge il PATH aggiornato dal registro.
- Programma presente ma che non parte → messaggio "riavvia Visual Studio".

## Limiti noti
- Avanzamento senza percentuale (svn non dà un totale): barra indeterminata + contatore.
- Icone standard di VS (niente "?" stile Git per i non versionati).
- Se è installato un altro provider SVN (AnkhSVN, VisualSVN) VS fa scegliere quale usare.
