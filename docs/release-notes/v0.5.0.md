# SVNAssist 0.5.0 — Branch/Tag, patch con backup, lock di altri utenti

Si installa come le precedenti (`SVNAssist.vsix`, Visual Studio chiuso).

## Branch e tag
- **SVN Branch/Tag...** (menu SVNAssist, "Altre azioni" in Changes, pulsante nel selettore Switch): branch o tag da HEAD del ramo, da una revisione o dalla working copy (con le modifiche locali). Messaggio precompilato, opzione **Passa subito al nuovo branch**. Nome validato; un nome già esistente dà errore senza chiudere il dialogo.
- **Layout del repository**: oltre all'impostazione `repoLayout` nelle Options, se l'URL non corrisponde SVNAssist rileva da solo le cartelle (trunk/main, branches/branch, tags/tag). Usato da Switch, Merge, Branch/Tag e dall'etichetta del ramo.

## Patch e backup
- **Create Patch...** (Changes, su sezione, file o selezione; menu Extensions) e **Apply Patch...** con anteprima (`svn patch --dry-run`), file toccati, rifiuti e conflitti.
- **Backup automatico** prima di **Revert di tutto** e **Annulla merge**, in `<working copy>\.svn-assist\backups` (non compare tra i non versionati). Dopo l'operazione c'è **Ripristina modifiche**; il backup si elimina dopo il ripristino o alla prossima operazione. Se manca spazio su disco chiede se procedere senza backup. Pulizia automatica: oltre 7 giorni o 200 MB.
- I file binari non entrano nel diff: lo segnala il messaggio di stato.

## Conflitti e lock
- **Commit con working copy indietro**: prima del commit SVNAssist controlla il server; se qualcuno ha committato sul ramo avvisa (la tua copia locale non avrebbe il loro lavoro) e propone SVN Update. Se succede comunque, dopo il commit avviso e pulsante **SVN Update ora**; l'indicatore resta arancio.
- **Lock di altri utenti** nella finestra Changes: lucchetto con "Bloccato da <utente>" (data e commento), aggiornato dal controllo HEAD periodico.
- **Usa la mia per tutti / Usa la loro per tutti** per i conflitti di testo (conferma con elenco). Conflitti ad albero e di proprietà esclusi.
- **Avviso al commit** se un file contiene marcatori di conflitto (`<<<<<<<` … `=======` … `>>>>>>>`).
- Stato più completo: conflitti di proprietà, ostruiti, incompleti, tree conflict.

## Avanzamento
- **Percentuale vera** per Switch, Update e Update to revision quando il totale si ricava (`svn diff --summarize`, max 10 s); altrimenti barra indeterminata come prima.
- **Update to revision** ha la finestra di avanzamento con Annulla.
