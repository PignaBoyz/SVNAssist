# SVNAssist 0.7.2

Data di rilascio: 2026-11-25.

## Correzioni

- **Regole di commit nel profilo utente.** Prima: **Genera con AI** leggeva le regole personali solo da `%USERPROFILE%\.copilot\copilot-instructions.md`, mentre Visual Studio 2026 (anche per i messaggi di commit di Git) le legge da `%USERPROFILE%\copilot-instructions.md`: per avere le stesse regole in SVNAssist e in Git servivano due copie. Ora: SVNAssist legge anche `%USERPROFILE%\copilot-instructions.md`, quindi basta un solo file nel profilo.
  - Se lo stesso testo è in entrambi i file, viene usato una volta sola.

## Requisiti e installazione

Installazione: sostituisce la 0.7.1. Chiudere Visual Studio e avviare il file VSIX della release.

<details><summary>Dettagli tecnici</summary>

Collaudo: `docs/verifica/0.7.2/checklist.md`.

- `CommitInstructions.Load`: dopo `~/.copilot/copilot-instructions.md` legge `~/copilot-instructions.md` (file personale di Visual Studio 2026, lo stesso salvato dalle "memorie" di Copilot); saltato se il testo coincide con quello di `~/.copilot`. Ordine invariato: regole globali prima, regole del progetto in fondo.
