# SVNAssist 0.2.0

> **La 0.1.0 è deprecata**: disinstallala e installa la 0.2.0 (il tag v0.1.0 resta solo come storico).

## Installazione
Scarica `SVNAssist.vsix` qui sotto e aprilo con doppio click (Visual Studio chiuso). La demo interattiva è nello zip `svnassist-demo`.

Requisiti: Visual Studio 2026 (18.x; la 2022 è dichiarata ma non ancora provata), `svn.exe` (SlikSVN, TortoiseSVN con command line tools o altro), **.NET 10 Runtime** (se manca, SVNAssist propone di installarlo da solo o apre la pagina giusta: ".NET Runtime 10.x – Windows x64 installer").

## In breve
Nuova architettura: finestre in WebView2 con lo stesso design della demo, logica SVN e AI in un servizio .NET 10 separato (se cade, Visual Studio no).

## Novità principali
- **Pannello SVN Changes stile Git**: albero vero con tastiera, filtro, sezioni Staged / Modifiche / Non versionati; **Commit All** se Staged è vuoto, **Commit Staged (n)** altrimenti; Canc elimina (con conferma); feedback visibile su ogni azione.
- **Show Log come documento** nell'area editor: tabella revisioni leggibile, filtri per autore/testo/percorso/date, file cambiati, confronto tra due revisioni (Ctrl+clic). Anche per file e cartelle da Esplora soluzioni.
- **Diff nativo di Visual Studio** ovunque (working copy, revisioni, cartelle): TortoiseSVN non serve più.
- **SVN Update to revision** con scelta della revisione da elenco, **SVN Cleanup** (anche come pulsante quando la working copy è bloccata), **Lock / Unlock**.
- **Login SVN** solo se le credenziali in cache mancano o scadono (cache standard di Subversion, condivisa con TortoiseSVN); con l'accesso integrato di Windows non compare mai.
- **Procedura guidata per l'AI**: scegli il provider (GitHub Copilot, Claude Code, Claude API, GitHub Models), installa i prerequisiti, fai login e scegli il modello senza uscire da VS. Riapribile da Extensions > SVNAssist > "Change AI Provider...". Prerequisiti verdi/rossi in basso, cliccabili.
- Temi chiaro / scuro / blu / alto contrasto con cambio a caldo.

## Correzioni
- **Tema scuro/chiaro/blu**: niente più testo nero su nero; finestre Changes e Log usano i colori di Visual Studio.
- **Genera con AI**:
  - se l'AI non è configurata ti propone il login nel terminale (`gh auth login --web` o `claude`), in alternativa il token; il popup si ripresenta a ogni click (prima, chiuso una volta, non si apriva più nulla);
  - ogni errore o annullamento è mostrato nella barra di stato (prima: "OK" e nessun messaggio);
  - i file aggiunti, eliminati, vuoti o binari compaiono nel messaggio;
  - con molti file modificati funziona comunque (diff compattato);
  - segue le regole di commit in `.github/copilot-instructions.md`, `.github/instructions/*.instructions.md` e `~/.copilot/copilot-instructions.md`.
- "Seleziona tutto" spunta solo la sezione Modifiche (non più bin/obj non versionati).
- Il setting **Working Copy Path**, se impostato, vince sul rilevamento automatico (anche nel Log).
- Se un'operazione è già in corso, un nuovo click mostra "Operazione in corso…" invece di non fare nulla.
- Voci dei menu contestuali aggiornate quando lo stato di un file cambia.

## Novità
- Modelli AI scelti da **tendina** (Claude, Copilot, GitHub Models); default Claude: **Sonnet** (era Opus, più costoso).
- Prerequisiti filtrati per provider, con nota su login, chiave e costo.
- GitHub Models usa `openai/gpt-4o-mini`.
- Release automatiche da GitHub Actions.
- **Lingua dell'interfaccia Italiano / English**: Extensions > SVNAssist > Language / Lingua (Automatica = lingua di Visual Studio, Italiano, English) o Tools > Options. Cambia a caldo finestre, messaggi del servizio, dialoghi e impostazioni, senza riavviare VS. I nomi dei comandi SVN e i messaggi di svn.exe restano invariati; la lingua dei commit message AI è un'impostazione separata. Alcune voci di menu di VS sono ora in inglese standard SVN ("Change AI Provider...", "Diff with BASE", "Show Log", "Add to Ignore List").
