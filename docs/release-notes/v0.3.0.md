# SVNAssist 0.3.0 — Switch e Merge da Visual Studio

Il flusso quotidiano "porto le modifiche tra trunk e branch" ora si fa senza uscire da Visual Studio e senza TortoiseSVN.

## Installazione
Scarica `SVNAssist.vsix` qui sotto e aprilo con doppio clic (Visual Studio chiuso). Se hai la 0.2.0 viene aggiornata. La demo interattiva è nello zip `SVNAssist-demo`; i sorgenti sono negli archivi "Source code".

Requisiti: Visual Studio 2026 (18.x), `svn.exe` 1.8 o successivo (SlikSVN, TortoiseSVN con command line tools o altro), .NET 10 Runtime (se manca, SVNAssist propone di installarlo).

## Novità

### Switch
- Ramo corrente sempre visibile nella finestra **SVN Changes**; **Switch...** da lì o da Extensions > SVNAssist.
- Selettore veloce con **usati di recente** e ricerca immediata; **vista estesa** per repository con centinaia di branch e tag: filtri per nome, tipo, autore e periodo, ordinamento per nome, data, revisione o autore.
- Layout del repository configurabile (`trunk/branches/tags`, anche con il progetto alla radice o in una sottocartella).

### Merge
- **SVN Merge...**: scegli il branch e il Log si apre come documento con le sole **revisioni da unire**.
- **Anteprima** (dry-run), **Merge tutto** e **Merge selezionate** (cherry-pick).
- Working copy sporca o a revisioni miste: spiegazione chiara e pulsanti per rimediare subito (**SVN Revert di tutto…**, **SVN Update ora**).
- **Annulla merge** dal banner, con conferma ed elenco dei file.
- Il messaggio in stile TortoiseSVN ("Merged revision(s) 8-10 from …" con le revisioni unite) finisce nei **Recenti**: lo inserisci quando vuoi e resta anche dopo un revert.

### Conflitti
- Riquadro **Conflitti** ampio in SVN Changes: per ogni file **Apri editor di merge** (editor a 3 vie di Visual Studio), **Usa la mia**, **Usa la loro**, **Segna come risolto**.
- **Conflitti ad albero** raggruppati con **Segna tutti come risolti** (o uno per uno).
- I file di appoggio di svn (`.mine`, `.rNNN`, `.merge-left/right`, `.working`) stanno sotto il file in conflitto, non più tra i non versionati.

### Diff e annullamento delle righe
- **Annulla le singole righe** come in Git: pulsante Annulla accanto a ogni blocco nel diff, oppure tasto destro **SVN: Revert Selected Changes** su una selezione.
- **Alt+F8 / Shift+Alt+F8**: modifica successiva / precedente nel diff (scorciatoie personalizzabili nelle opzioni).
- Doppio clic su un file **aggiunto** o **non versionato** apre il file intero.
- Il Log si apre sempre nell'area documenti, accanto ai diff.

### SVN Changes
- **Indicatore della revisione** in basso: verde se sei all'ultima, arancio con "disponibile rN — SVN Update" se altri hanno committato (controllo leggero ogni 5 minuti, solo lettura, configurabile o disattivabile in Tools > Options).
- I messaggi di esito spariscono dopo qualche secondo; gli errori restano.
- **Recenti**: pannello con ricerca e anteprima degli ultimi 25 messaggi per repository.
- Tasto destro su **Changes** o **Staged** → **SVN Revert di tutto…** (con conferma).

### Genera con AI
- Legge **tutte** le modifiche reali: diff grandi divisi in blocchi, riassunti e ricomposti in un messaggio completo (titolo + elenco per area), anche su centinaia di file.
- Segue le regole di commit del progetto e globali: `.github/copilot-instructions.md`, `.github/instructions/*.instructions.md`, `CLAUDE.md`, `AGENTS.md`, `~/.copilot/copilot-instructions.md`, `~/.claude/CLAUDE.md` (es. Conventional Commits).
- Errori "No response was returned" (Copilot) e "'0' is an invalid start of a value" (OpenAI-compatible): nuovo tentativo con una richiesta più piccola e messaggio chiaro.
- Niente più blocchi ``` intorno al messaggio generato.

## Correzioni e altro
- Le finestre di SVNAssist ripristinate da Visual Studio all'avvio non danno più "Failed to find the tool window".
- Rimosso il sottomenu SVN da Esplora soluzioni (ridondante con la finestra SVN Changes).
- Nuovo `tools/setup-sim.ps1`: crea un repository di prova realistico (storico, 150 branch, conflitti) per provare tutto in locale.

## Limiti noti
- Il pulsante Annulla accanto ai blocchi del diff è nuovo e non è stato ancora visto in tutte le viste diff di Visual Studio: se non compare, usa tasto destro > **SVN: Revert Selected Changes** (stesso risultato).
- Crea branch/tag e procedura guidata dedicata al merge: in arrivo.
- Su repository molto lenti non c'è ancora l'avanzamento per Switch/Merge.
- Provato su Visual Studio 2026 (18.x); la 2022 è dichiarata ma non provata.
